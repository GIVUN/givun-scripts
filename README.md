# סקריפטים של גיוון – עימוד ועיצוב מקצועי

## התאמת פסקה (InDesign)
כמו פיט 7 בתג: שורה+ / שורה−, מילה+ / מילה−, שורה אחרונה מלאה, מילה בודדת, ושורה+ / שורה− בעמוד או בטור.

### התקנה (פעם אחת)
1. להוריד את הקובץ: [hatamat-piska.jsx](https://raw.githubusercontent.com/GIVUN/givun-scripts/main/hatamat-piska/hatamat-piska.jsx) (קליק ימני ← "שמירת קישור בשם").
2. לשמור אותו בשם **התאמת פסקה.jsx** בתיקיית הסקריפטים של אינדיזיין
   (באינדיזיין: חלונית Scripts ← קליק ימני על User ← Reveal in Explorer).
3. להפעיל מחלונית Scripts.

מכאן הסקריפט מתעדכן לבד: כשיוצאת גרסה חדשה מופיעה הודעה "יש גרסה חדשה – לעדכן?".
